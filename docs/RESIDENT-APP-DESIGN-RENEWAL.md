# Sky Garage 사용자 앱 디자인 리뉴얼

대상: `/app` 사용자 앱. 네이비, 부드러운 민트, 아치 형태의 게러지 모티브를 사용한다. 기존 SGP 서비스의 인증·결제 경로를 유지한다.

## 변경 화면

- 홈: 주차 서비스와 바로가기를 먼저 배치하고 지갑, 소속 단지, 최근 이용 순으로 구성.
- 탐색: 모바일 하단 메뉴 / 데스크톱 좌측 메뉴. 주차 메뉴 추가, 결제는 홈 바로가기에서 진입.
- 로그인·가입: 공통 브랜드 헤더와 배경, 전화번호 키보드와 자동완성, 가입 안내 가독성 개선.
- PC 접근 제한 제거. 320px 이상 화면과 모바일 안전 영역 대응.
- 홈의 조회 중, 빈 내역, 조회 실패, 재시도 상태 제공. 결제 `pending`은 홈에서 ‘정산 대기’로 표시하고 실제 차량 위치나 주차 상태로 단정하지 않음.
- 키보드 탐색, 본문 바로가기, 현재 메뉴 표시, 동작 축소 설정 지원.

## 범위 및 확인 필요 사항

Supabase 스키마, RLS, 인증 처리, 하드웨어 명령은 변경하지 않았다. 홍보 페이지·관제 화면 및 지갑·결제 등 하위 화면 본문 디자인은 이번 변경 범위에 포함하지 않는다.

기존 `/app/map` 화면에는 결제내역을 임의 좌표로 매핑하고, 내역이 없으면 예시 차량을 생성하는 코드가 있다. 이 화면은 실제 차량 위치 및 하드웨어 연동 완료의 증거로 사용할 수 없다. 실제 운행 정보 연결은 별도 검증이 필요하다.

2026-10-18 Netlify 프로젝트 `skygarage-doelv` 생성 및 GitHub 연동 완료. 현재 운영 배포 브랜치는 `design/skygarage-resident-renewal`이며 `main`은 병합하지 않았다. 빌드 명령은 `npm run build`, 게시 폴더는 `dist`, Node.js는 24를 사용한다. `.netlify` 로컬 상태는 Git에서 제외한다.

공개 앱: https://skygarage-doelv.netlify.app/app

## 검증

- `npm run build`: TypeScript 검사와 프로덕션 빌드 통과. 기존 대용량 번들 경고 존재.
- 변경한 TSX 세 파일에 대한 ESLint 검사 통과.
- Chromium에서 Supabase 응답을 모의 처리해 PC 로그인, 회원가입 진입, 인증 후 홈, 주차·결제 경로, 빈 데이터, 오류·재시도 확인.
- 320 / 390 / 768 / 1440px 폭에서 홈의 수평 넘침 없음 확인.
- 모의 응답을 이용한 화면 검증이며 실제 계정 가입, SMS 발송, 결제, 차량 호출 및 기기 검증은 수행하지 않음.
