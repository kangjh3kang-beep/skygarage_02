# 회원가입 주소 검색

회원가입 주소등록 단계에 ‘주소 검색’ 버튼을 추가했다. Kakao 우편번호 공식 스크립트를 버튼 클릭 후 불러오고, 새 창 대신 대화상자 안에 검색 화면을 넣는다. API 키는 필요하지 않다.

- 도로명/지번 선택 결과와 우편번호 자동 반영.
- 선택 후 상세주소 입력란으로 포커스 이동.
- 직접 입력 및 로딩 실패 시 재시도 지원.
- 창을 닫거나 다시 열어도 입력값 유지.
- 기본주소를 수동 수정하면 이전 우편번호를 지워 잘못된 조합이 저장되지 않도록 함.
- 가입 시 우편번호가 있으면 기존 address 텍스트 컬럼에 `(우편번호) 기본주소` 형식으로 저장. 상세주소는 기존 address_detail 사용.

## 검증

프로덕션 빌드, 변경한 화면의 ESLint, 모의 SMS 인증→정보입력→주소선택 흐름 확인. 로딩 실패/재시도, 주소 자동 입력, 상세주소 포커스, 닫기/재열기, 390px 화면 넘침 없음, 가입 차단 오류의 한국어 안내를 브라우저에서 확인했다. 실제 문자나 계정을 생성하지 않았다.

## 별도 회원가입 차단

Supabase `/auth/v1/settings` 조회에서 `disable_signup=true`, `mailer_autoconfirm=false`를 확인했다. 화면의 ‘Signups not allowed for this instance’는 주소 검색과 별개의 서버 설정 오류다. 신규가입 허용 및 전화번호 인증 기반 가입 흐름은 별도 조정 대상이며 이번 변경에서 인증 정책을 변경하지 않았다. 기존 합성 이메일(`전화번호@sgp.skygarage.app`) 방식은 일반 메일 인증을 받을 수 없으므로 가입 허용 토글만 변경해 전체 가입 검증이 끝났다고 판단하지 않는다.
