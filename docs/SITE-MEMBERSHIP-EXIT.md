# 회원 본인의 현장 소속 해지

검증 기준일: 2026-10-24 KST. 범위는 특정 단지·시설의 소속 종료다. 전체 계정 탈퇴, 개인정보 삭제·보존 기간 확정, 물리 장비의 권한 회수 인수를 포함하지 않는다.

## 사용 방법

1. 공식 앱 설정(`/app/profile`)에 로그인해 내 소속을 조회한다.
2. 승인된 소속 중 종료할 현장의 **이 현장 소속 해지**를 선택한다. 현장명과 영향 범위를 확인한다.
3. 사유를 선택하고 확인란에 **소속 해지**를 정확히 입력한 뒤 확정한다. 취소하면 변경하지 않는다.
4. 처리 후 최신 소속이 회수 상태인지 확인한다. 다른 현장 소속은 유지된다. 다시 이용하려면 새 초대·신청·독립 승인을 거친다.
5. 로그인 세션 오류는 다시 로그인한 뒤 조회한다. 변경 충돌은 최신 상태를 조회한다. 응답 유실 시 같은 내용으로 재시도하면 동일 요청 영수증을 반환한다. 영수증은 현재 권한의 증명이 아니다.

관리자는 회원 관리(`/admin/residents`)에서 동일 현장을 선택하고 회원 목록과 변경 이력의 **본인 소속 해지**를 확인한다. 현재 계정에 별도로 부여된 관리자·현장 담당자 역할을 해제하는 작업은 이 기능과 별개다.

## 변경과 보존 경계

| 항목 | 처리 |
|---|---|
| 본인·선택 현장의 활성 소속 | revision 확인 후 revoked, 원래 세대 연결·표시 보존 |
| 본인·선택 현장의 등록 차량 | revoked로 전환; 실장비에 회수 명령을 전송하지 않음 |
| 동일 소속의 잔여 pending 신청 | withdrawn으로 종료해 오래된 승인에 의한 복구 방지 |
| 기존 승인 신청·주장 동호·명령·감사 이력 | 유지, 새 해지 이력·감사·영수증 추가 |
| 다른 현장·다른 회원 | 변경하지 않음 |
| Auth 계정·회원 프로필·별도 직원 역할 | 삭제·회수하지 않음 |
| 결제·정산·ERP 원장 | 이 명령의 변경 대상이 아님; 금융 통합 인수는 별도 |

보존 기간과 전체 회원 탈퇴·개인정보 삭제의 법적·운영 정책은 아직 확정되지 않았다. 이 작업을 개인정보 삭제 요청의 완료로 표시하지 않는다. 관련 T03은 일부 구현, T06은 구축 예정 상태를 유지한다.

## 서버 계약

`platform_membership_command`의 `leave` 동작에 `site_id`, `expected_revision`, 5~500자 사유, 확인 문구를 전달한다. 대상 회원은 `auth.uid()`로 고정한다. 다른 user_id를 넣으면 거부한다. 일반 회원 AAL1에서도 사용할 수 있고 관리자 역할은 필요하지 않다. 기존 관리자 변경의 AAL2·현장 권한 검사는 유지한다.

비공개 `assert_live_member_session`은 JWT의 session_id에 해당하는 실제 Auth 세션과 사용자 일치, 세션 만료, 계정 금지·삭제, 활성 프로필을 확인한다. 세션 행을 공유 잠금해 진행 중 세션 삭제와 순서를 맞춘다. 로그아웃된 JWT는 서명 만료 전이라도 거부하며, 캐시된 영수증 반환 전에도 확인한다. 이 검사는 새로운 문자 수신이나 최근 본인확인을 입증하지 않는다. 테스트용 세션·문자 확인 상태를 운영 DB에 생성하지 않는다.

배타적 actor/현장 잠금, 소속 CAS, 상태 변경, 차량 회수, 잔여 신청 종료, 감사·영수증을 하나의 트랜잭션으로 처리한다. 중간 오류는 모두 롤백한다. 운영 중지 현장에서도 권한을 줄이는 소속 해지는 허용한다. 과거 요청 영수증 재조회는 재가입한 소속에 다시 변경을 가하지 않는다.

SQL 원문: `supabase/sql/site-membership-exit.sql`. 기존 적용 마이그레이션을 편집하지 않고 후속 적용한다.

## 운영 반영 기록

운영 DB 적용: `site_membership_exit`, 실제 서버 버전 `20261023211758`. 해당 버전의 마이그레이션은 검증 원문과 바이트 단위로 같다. 적용 후 세 함수 원문 해시가 로컬과 일치했고 빈 search_path·기존 공개 RPC의 익명/서비스 역할 실행 금지·비공개 도우미의 모든 클라이언트 실행 금지를 확인했다. 회원 소속 2건·차량 0건·신청 0건·업무 이력 0건으로 적용 전후 건수는 동일하다. 운영 계정·문자 인증 성공·가상 세션을 생성하지 않았다.
