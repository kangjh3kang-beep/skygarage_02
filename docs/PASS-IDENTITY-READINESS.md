# PASS 본인확인 확장 준비

## 현재 동작과 범위
- SOLAPI SMS는 번호 소지 확인이다. 이름·생년월일·명의자 일치를 확인하는 PASS 본인확인과 구분한다.
- 기존 `sgp_users.is_verified`, `phone_verified_at`, `kyc_level=1`은 휴대폰 인증만 의미한다. PASS 완료나 실명·입주 자격의 근거로 사용하지 않는다.
- `registration-proof.ts`가 가입의 인증 증거 확인을 담당한다. 기존 요청은 `sms_otp`로 처리한다. `method=pass`는 501로 거절한다. 클라이언트의 `verified`, CI, 등급, 이름 일치 주장은 신뢰하지 않는다.
- PASS 버튼·실제 인증 API·콜백·CI/DI 저장·추가 DB 마이그레이션은 아직 활성화하지 않는다. 기존 회원은 그대로 로그인한다.

## 제공사 확정 후 구현 순서
1. NICE/KCB/다날/KCP 등 제공사의 PASS 지원 상품·계약·반환 항목·서버 조회/서명 검증 명세를 확인한다. 포트원은 연동 경로의 한 후보이며 선정한 상태는 아니다. 휴대폰 본인확인과 PASS 인증서 상품을 구분한다.
2. 서버 전용 비밀값·상점/사이트 ID·운영/테스트 채널을 분리한다. 키를 VITE 환경변수나 브라우저에 넣지 않는다.
3. 서버가 고엔트로피 attempt ID와 브라우저 바인딩을 만들고, private 스키마에 목적(signup/upgrade), 사용자 ID, 제공사 거래 ID, 만료, 처리 상태를 저장한다. 공개 API에는 opaque ID만 반환한다.
4. 제공사 인증창을 연다. 등록한 HTTPS 콜백 주소만 허용하고 임의 return URL은 거절한다. `skygarage.app` 연결 이후 운영 콜백 도메인을 등록한다. 현재 공식 `www.skygarage.net/app`와 테스트 도메인은 별도 등록한다.
5. 브라우저 성공 화면·리다이렉트 파라미터만으로 완료하지 않는다. 서버가 계약된 제공사 API 재조회/암호화·서명 검증을 수행하고 거래 ID·가맹점·인증 완료 상태·목적·바인딩·만료를 대조한다.
6. 결과를 `PassIdentityAdapter.verify` 반환 형식으로 정규화한다. 인증기관이 검증한 항목만 사용한다. 제공사가 반환하지 않거나 검증하지 않은 항목은 미확인으로 남긴다.
7. private evidence를 1회 소비하는 트랜잭션과 계정 연결을 구현한다. 회원의 인증 강화는 로그인 사용자와 바인딩된 `upgrade` 증거만 허용한다. 전화번호 변경만으로 기존 계정을 자동 병합하거나 소유권을 넘기지 않는다.
8. 이름·생년월일·전화번호 불일치, 외국인·알뜰폰·법인폰·취소·앱 복귀·인증 만료·동시 콜백·재전송·제공사 장애를 검증한다. 보호 작업에 PASS가 필수라면 장애 시 SMS로 자동 낮추지 않는다.
9. 기존 회원에게 단계적으로 추가 본인확인을 제공하고, 서버가 확인한 evidence ID와 verification method/assurance를 별도 저장한다. SMS 기록을 PASS 완료로 일괄 승격하지 않는다.

## 개인정보와 권한 설계
- 주민등록번호 전체를 앱/DB/로그/분석 도구에 수집하지 않는 구조를 유지한다.
- CI/DI가 필요한 기능과 보유기간·동의·삭제 절차를 먼저 확정한다. 필요하면 서버 전용 HMAC 지문(키 버전 포함)을 private 스키마에 저장한다. 지문도 보호 대상이며 무기한 보관을 기본값으로 삼지 않는다.
- CI/DI 원문·제공사 응답·인증 토큰·이름·생년월일을 URL, 브라우저 저장소, JWT user_metadata, 오류 로그에 넣지 않는다.
- 공개 프로필에는 필요한 최소 상태만 노출한다. 프런트엔드는 확인 상태를 직접 수정할 수 없다. 신원 확인이 곧 단지 입주·출입 권한은 아니며, 해당 권한은 별도로 판정한다.
- 계약 및 개인정보 검토 후 private evidence 테이블/RLS/서버 권한 마이그레이션을 별도 검토·적용한다.

## 연동 완료 판정
- 실제 제공사 테스트/운영 인증, 서버 결과 대조, 타인 거래·콜백 위조·중복 소비 차단 검증을 통과해야 PASS 완료로 표시한다.
- 계약/인증키 입력만으로 즉시 운영 전환하지 않는다. 브라우저·Android·iOS 복귀, HTTPS 인증서, 콜백 등록, 동의 화면, 개인정보 삭제까지 확인한다.
